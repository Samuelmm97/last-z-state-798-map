# State 798 shared data

## Language

**Player identity**: The game's player ID, retained through name and alliance changes. A name alone does not establish identity.

**Power observation**: A measured power value with its own observation time. The States 792–815 workbook is authoritative for current power.

**Hero component power**: The hero contribution in a player's five-part power breakdown. It is distinct from an older hero leaderboard reading.

**Position observation**: A positively observed HQ location in a particular state and world, with an observation time. Absence from a scan does not prove relocation.

**Proposed placement**: A location someone is intended to occupy. It is separate from their observed position.

**Held placement**: An observed placement the coordinator has chosen to retain while replanning.

**Teleport opening**: An empty position that fits an entire enemy HQ footprint inside the defended formation.

**Double opening after a loss**: Two non-overlapping enemy HQ footprints that become possible when one defending HQ disappears.
